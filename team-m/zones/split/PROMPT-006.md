## Твоя зона — что такое Split
Split = мониторный микшер-суфлёр: вкладка **Split** в нижнем доке Репетиции. Панель из 3 колонок:
- **Route** — куда идёт музыка: селект «Send music to», большая кнопка **SPLIT/STOP**, «Music with me» (тумблер+слайдер), Timing (Adjust timing on: Headphones/Speakers, 🎧-селект устройства);
- **Line Up** — калибровка задержки: статус-чип (Not synced / Synced / Recheck / Estimated / 🎵 Live / 🔊 Sound), чипы-переключатели **Pulse/Voc**, задержка в ms, круглый барабан-шкала 0–500ms (шаг 5), кнопки ±5/±10, **🔒 Adjust** → режим теста (Cancel / ✓ Sounds right);
- **Auto Mix** — автоматика вокала по секциям: Back Vocal master (точка+слайдер), 6 dual-рядов Intro / Verse / Pre-chorus / Chorus / Bridge / Outro (левая половина main, правая Back Vocal).
Стыки зоны с хабом: кнопка SPLIT в деке, V-Mix, 🎤, вкладка Split в панели табов.
