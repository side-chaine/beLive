## УДАРЫ ПО 005 (T1-T5)

**T1 · MessageChannel — КРИТИЧНО, «дизайн без потребителя»:**
005 спроектировал транспорт, но приёмник «пишет локальные CSS-вары» — слайды = произвольные user-загруженные .html (StepWorkspace.tsx:460-466 accept=".html"). В opaque origin (sandbox="allow-scripts" без same-origin) родитель НЕ МОЖЕТ инжектить скрипт внутрь. Мост работает только для HTML, **авторизованных с нашим runtime-сниппетом** — контракта авторинга НЕ СУЩЕСТВУЕТ. Все существующие rec_html_* блобы мертвы для моста. Геймчейнджер для текущих пользователей = ноль эффекта до пере-авторинга.

**T2 · pre-mix — СЕРЬЁЗНО, гашение режет флагман:**
stem-reactive.ts:43-51 (C5 recording-safe) зануляет ВСЕ stem-вары при isRecording → Show-REC ставит isRecording=true (recording.store.ts:110) → **stem-визуал в HTML умирает ровно во время записи** — главном сценарии L4. При этом audio-reactive.ts (нет isRecording-чека) продолжает публиковать 5 вар → в записи слайд получает живые --bl-audio-* и мёртвые --bl-stem-*. Непоследовательный визуал в флагманском прогоне. + teacher-сценарий БЕЗ трека (T5 «Урок») — транспорт idle, все 8 вар = 0 → HTML-динамика для учителя мертва по построению.

**T3 · zod-ZIP — СЕРЬЁЗНО, валидатор не того валидирует:**
zod валидирует show.json ПОСЛЕ распаковки. ZIP грузится целиком в память (upload.service.ts:693-695 → readFileAsArrayBuffer :136-148 → JSZip). Zip-бомба 50MB → GB в памяти до первого zod-чека. Magic-bytes на клиенте нет (классификация по расширению :718-722). «Безопасный импорт бесплатно» — бесплатно только JSON, не архив.

**T4 · tools — КРИТИЧНО, канал не несёт tool_calls:**
gateway ВЫРЕЗАЕТ tool_calls: gateway/src/index.ts:294 `const token = parsed.choices?.[0]?.delta?.content ?? ''` — единственное, что проходит трансформ. Streaming tool calls через gateway сегодня НЕВОЗМОЖНЫ; «парсинг дельт поверх» = правка чужого бэкенда. + capability-детект /v1/models?supported_parameters=tools недоступен гостям (gateway не проксирует /models) — а гость = дефолт-юзер. Фолбэк [ACTION:] жив (ai-tools.ts:124-152) — «4 макро-тулза» деградируют до грамматики для большинства.

**T5 · шаблоны — ТУЧА:** «Стемы»-шаг шаблона музыканта ссылается на фичу, которой нет (featureRegistry = 1 фича, :62-81) = шаг-тупик.
