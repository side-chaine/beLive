## Твоя зона — что такое Studio
Studio = N-Stem микшер-среда: вкладка **«Studio»** в нижнем доке Репетиции (модуль 'mixer', order 25). Что на панели:
- **8 канальных полос** (ChannelStrip): Instrumental, Vocal, Drums, Bass, Keys, Guitar, Back Vocal, Other — у каждой: label + **VU-метр** (CSS-полоски, пульсируют через rAF) + вертикальный **фейдер** (0..1) + кнопки **M** (mute) / **S** (solo);
- **Тулбар:** кнопка **Stems** (вкл/выкл стемы-режим всей зоны), кнопка **Visual** (визуальный режим → вместо полос InstrumentStrip), селект микрофона;
- **Шины BusFader18** (music-bus / vocal-bus) — в коде формула `effective = clamp(raw) × clamp(busFactor)`; тебе видны только результаты: музыкальная шина дополнительно рулится **красным фейдером в доке** (СТЫК с хабом — смотришь по запросу головы);
- **V-Mix-кнопки в самой панели Studio НЕТ** — она в доке (ControlDeck) и ведёт в мониторный слой Split: для тебя это стык, не твоя зона.
