## §3 ПРАВИЛА PROMPT-CRAFT ДЛЯ ATRIA — СКИЛЛ ДЛЯ ВСЕХ

> Эта секция — переносимая. Вшить в промпты 001/002/005/009 как «## ATRIA PROMPT-CRAFT (от 007)».

**P1 КАНОН-СТРОКА.** В каждый диспатч, дословно: `tsc=181 · vitest=824/68 · PARITY PASS · замер 17.09`. Без неё агенты несут прошлые цифры (D1).
**P2 ФОРМАТ + МИНИАТЮРА.** Требуемый ответ показан 3-6 строками примера. Atria приземляется на формат мгновенно.
**P3 ЖЁСТКИЙ ЛИМИТ.** «≤N строк» работает. Без него — оверпродукция (D3).
**P4 file:line ЯКОРЯ.** Вместо пересказа «метрики мертвы» → «metrics.store.ts:122 — 7/8 actions, 0 вызывателей». Atria по якорю выдаёт точность, по пересказу — домыслы.
**P5 ЛИЧИНА + КАНОН БОССА + ОРУЖИЕ.** Каждый агент уже имеет личину («Ты — 001, CEO-Архитектор», «Канон Босса: Ювелир»). В диспатче личину поднимать первой строкой, канон — второй. Для адверсариала: квота ударов + оружие.
**P6 СКВАД-ПАМЯТЬ.** Второй круг агента в прогоне = его прошлый вклад из этого же прогона (§11.1). Atria на втором круге качественно точнее.
**P7 ТРИГГЕРЫ, НЕ ВИБРАЦИИ.** Ограничения как явные `if X → СТОП`, не как «будь осторожен». Atria исполняет триггеры буквально (S3).
**P8 «ДУМАЙ ШАГ ЗА ШАГОМ».** Для reasoning-ролей — обязательно; проверено на 001/009.
**P9 ПРЕ-РЕЗОЛВ.** Грунтую то, что агент не может сам (Context7 ID, пути к файлам, номера строк).
**P10 ПОСЛЕДОВАТЕЛЬНОСТЬ.** reasoning-агенты — строго по одному; scout/research-класс (005, explore) — параллельно (§11.5).
