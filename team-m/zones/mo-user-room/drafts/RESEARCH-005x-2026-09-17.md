**Почему Blender, не RPM:** видение = стилизованные образы и **дракон**; RPM = только гуманоиды, бесплатные анимации FBX «не предназначены для других персонажей»; плюс сетевая зависимость от чужого CDN (оффлайн-first профиль). RPM остаётся как будущий магазин аватаров — **НО лицензия RPM-контента не верифицирована** (транспорт-ошибки на всех страницах лицензий) → решение по RPM только после юриста.
**Путь из Blender:** арматура (idle/dance/тренировка) + shape keys (эмоции, синх губ) → экспорт glTF 2.0 (.glb) с Animation + Shape Keys → `GLTFLoader.animations` → `AnimationMixer` + `clipAction`; морфы через `morphTargetDictionary/Influences` (пример `RobotExpressive.glb`). **Ограничение:** морфы только POSITION/NORMAL (TANGENT не поддерживается). Компрессия KTX2/Meshopt (`facecap.glb`, 52 blendshapes).
