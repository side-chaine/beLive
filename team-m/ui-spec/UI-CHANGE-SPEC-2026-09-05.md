# beLIVE · UI CHANGE SPEC

**Версия:** 006 Diagnostic Lock · **Дата:** 2026-09-05
**Источник:** сессия Никита + GPT · **Упаковка:** CEO_1 007
**Статус:** контракт (не генерим, пока 006 не пройдёт макет forensic'ом как заблокированный спек)

> **Главный тезис спецификации:**
> **beLive перестаёт делать громкость вспомогательным контролом. Баланс VOICE ↔ INSTRUMENTAL становится одним из главных органов приложения.**
> Цветовая система строится вокруг пары **синий = VOCAL / красный = INSTRUMENTAL**, а `beLiVE` становится визуальным продолжением этой логики (`be` = синий · `LiVE` = красный).

---

## 1. ТРЁХКОЛОНОЧНАЯ АРХИТЕКТУРА

```text
┌──────────────┬──────────────────────────────┬──────────────┐
│              │                              │              │
│ PERSONAL     │                              │  AI COACH    │
│ / USER       │       MAIN STUDIO            │  CHAT        │
│              │                              │              │
└──────────────┴──────────────────────────────┴──────────────┘
```

**Критично:** боковые панели — полноценные СОСЕДНИЕ пространства, НЕ наложение поверх центра.

- **Левая (PERSONAL):** Avatar → Progress → Track Progress → Practice Plan → Next Exercise = «Что со мной сейчас и что делать дальше?»
- **Центр (MAIN):** Track → Section → Lyrics → Transport → Vocal/Instrumental balance = главный визуальный фокус.
- **Правая (AI COACH):** Conversation → Suggestions → Exercises → Actions = рабочий чат с Coach, не декоративный.

## 2. ПЕРЕКЛЮЧЕНИЕ БОКОВЫХ КОЛОНОК

В **верхних углах центральной панели** — два компактных toggle (иконки, не большие кнопки):
- верхний левый: `[◀ Personal]`
- верхний правый: `[AI ▶]`

Логика: при выключении колонки **центральная автоматически расширяется. Пустого места не остаётся.**
`[USER] [MAIN] [AI]` ⇄ `[MAIN] [AI]` / `[USER] [MAIN]`

## 3. ВЕРХ ЦЕНТРАЛЬНОЙ КОЛОНКИ

- Сверху: текущий Section (напр. `Verse 1`) + небольшой `···`.
- Справа вертикально: **BPM** (`105`).
- Блок `4/4` / `C#m` **УБИРАЕТСЯ** из этого места (размер и тональность — во вторичный слой/контекстное меню).

## 4. BPM — НОВАЯ ЛОГИКА (±5)

```text
   +
 105
   −
```
Один клик = **±5 BPM** (105→110→115… / 105→100→95…). Вместо постоянного `4/4`.

## 5. ЦЕНТРАЛЬНЫЙ LYRICS / PERFORMANCE PLATE

Принцип текущего варианта: большая immersive-плашка — активная строка крупно, соседние приглушены, фон размыт, текст белый, lyric-states в оттенках системы, никакого визуального мусора.
**«Пользователь должен смотреть сюда и петь.»** Центр = performance.

## 6. TRANSPORT BAR (фундамент сохранён)

```text
LOOP   PREV   PLAY/PAUSE   NEXT   PITCH
```
- **LOOP** — влево: Loop Current Track / Loop Current Section (по режиму).
- **PREV / NEXT** — предыдущая/следующая точка или секция.
- **PLAY/PAUSE** — самая заметная кнопка.
- **PITCH** — вместо второй непонятной кнопки. Иконка ~ waveform/pitch-curve. Функция: **Live Pitch Detection** (realtime-анализ голоса). Компактная кнопка `〽 PITCH`, при включении — тонкий glow. НЕ огромный анализатор.

## 7. ГЛАВНОЕ НОВОЕ — VOCAL / INSTRUMENTAL BALANCE

Старую систему `Inst 100 / Voc 100 / B / P / M / VMix OFF` **убираем** (набор отдельных DAW-переключателей больше не нужен).
Вместо неё — единственный главный аудио-орган: **VOCAL ↔ INSTRUMENTAL**. Это визуальная подпись beLive.

## 8. НИЖНЯЯ ПАНЕЛЬ

Философия: **не удаляем функции — удаляем визуальный шум.**

```text
⌂ HOME ↔ STUDIO     |   AUDIO CONTROL (широкая центр. область)   |   ••• МЕНЮ
```
- **Левая кнопка** — контекстная: `Home` вне Studio, `Studio` внутри. ⇄.
- **Правая кнопка** `•••` — меню: Quest · Split · Show · Styles · Notes · … (функции не исчезают, прячутся в меню).

## 9. ЦЕНТР НИЖНЕГО БАРА = AUDIO CONTROL (вместо Split/Quest/Show)

Три горизонтальных fader'а:
```text
MASTER
────────────●────────

VOCAL          INSTRUMENTAL
🔵 ━━━━━━━●━━━━━━      🔴 ━━━━━●━━━━━━
```

## 10. MASTER FADER

Отдельный master-volume: **управляет ОБОИМИ нижними фейдерами одновременно**, НО **сохраняет относительный баланс**.
Пример: MASTER вниз → VOCAL 100→90, INST 100→90 (соотношение прежнее).
> Master не разрушает баланс. Меняет громкость всей пары.

## 11. VOCAL FADER (синий)
Уровень голоса. Вправо = громче. Цвет мягко усиливается вокруг активной позиции.

## 12. INSTRUMENTAL FADER (красный)
Левая = меньше инструментала, правая = больше.

## 13. ИХ ВЗАИМОДЕЙСТВИЕ (главное)

Не два скучных DAW-fader'а — они визуально **понимают друг друга**: синий/красный свет мягко усиливается у активного; при ~50/50 синий и красный **встречаются в центре**. Фирменный переход: **blue ↔ red**, не фиолетовый, не грязный градиент.

## 14. ЦВЕТНАЯ СИСТЕМА (ДНК beLiVE)

**НЕ `beLive = purple AI`, а `be = BLUE`, `LiVE = RED`.** Категорически НЕ чистые `#0000FF`/`#FF0000` (дешёво/агрессивно).

| Роль | Токен | Базовый | Активный |
|---|---|---|---|
| VOCAL / `be` | Electric Cyan-Blue | `#38A8FF` | `#58D5FF` |
| INSTRUMENTAL / `LiVE` | Warm Signal Red | `#FF5B5B` | `#FF7766` |
| DARK BASE | — | `#080A10` | — |
| Secondary blue | — | `#1677C8` | — |
| Secondary red | — | `#C93E45` | — |

## 15. beLiVE LOGO — СИСТЕМНЫЙ СМЫСЛ

```text
be   LiVE
🔵    🔴
```
`be` = Voice · `LiVE` = Music/Instrumental/Energy. Интерфейс повторяет ту же грамматику. Сильный брендовый ход.

## 16. НЕ «СИНИЙ VS КРАСНЫЙ»

Это НЕ противостояние. `vocal + instrumental` — два независимых потока **одной музыкальной системы**. Цвета сосуществуют, не конфликтуют.

## 17. ЛЕВАЯ PERSONAL COLUMN (проверить на перегруз)

1. Avatar (крупный, компактный) · 2. Progress (`VOCAL SKILL 72%`) · 3. Current Track (`From the Inside 48%`) · 4. Practice Plan (`✓ Breath Control / ▶ Verse 1 / ○ Pre-Chorus…`) · 5. ONE primary action (`START NEXT EXERCISE`).
Никаких десяти маленьких метрик.

## 18. AI COLUMN — Coach, не ChatGPT-клон

`beLive AI Coach ● Online` → сообщение → suggestion → action
```text
> Your ending is getting tense.
↓ Suggested Exercise: Release Tension
↓ ▶ Start
```
Не превращать правую колонку в Telegram.

## 19. ПРАВИЛО-ФИЛЬТР (главный критерий 006)

Что пользователь должен видеть **постоянно**:
1. active lyrics · 2. play/pause · 3. vocal/instrumental balance · 4. current section · 5. next useful action.
**Всё остальное вторично.**

## ГЛОБАЛЬНЫЙ ПРИНЦИП
**MORE AIR · LESS UI NOISE · FEWER PERMANENT BUTTONS · CLEARER PRIORITIES · STRONGER AUDIO IDENTITY.**
Экран = современный творческий инструмент. НЕ традиционный DAW. НЕ панель настроек. НЕ generic AI-приложение.

## 006 AUDIT QUESTIONS (для диагностики макета)
1. Необходимо? 2. Видно в нужный момент? 3. Конкурирует с active lyrics? 4. Можно в контекстный UI? 5. Иерархия = важность? 6. Усиливает BLUE VOCAL / RED INSTRUMENTAL? 7. 3-колоночность ясна? 8. Скрытие расширяет центр? 9. Нижний бар доминирует аудио-контролом? 10. MASTER отделим от VOCAL/INST? 11. Три фейдера понятны сразу? 12. Это beLive, не generic DAW?

**Финальный тест:** пользователь при первом взгляде должен сразу понять: «Я здесь, чтобы репетировать. Вот часть песни. Могу жать play. Могу контролировать голос vs инструментал. AI Coach здесь. Прогресс здесь.» Всё остальное вторично.
