# VERDICT-009 · Решение Суда по делу «Архитектура prompt-инжиниринга beLive» · 2026-08-25

> Полный текст без изменений. Иерархия доказательств суда: (1) исходники/схема → (2) документация → (3) логические следствия. Мнения сторон — гипотезы.

## ВЕРДИКТЫ ПО УЗЛАМ

### A · Несущая конструкция → **per-agent `prompt:{file:}` в проектном opencode.json** (скелет 001)
- JSON-маршрут — единственный, где ВСЕ нужные рычаги (prompt/steps/hidden/temperature/permission) доказаны одновременно.
- Markdown-агенты — отложенная альтернатива (возврат при отдельной верификации frontmatter на steps/hidden).
- Per-agent `instructions` Центра_5 — ОТКЛОНЕНЫ НАВСЕГДА: поля нет (высшая инстанция — схема).
- Производное правило безопасности: `{file:}` только в проектном конфиге (проектный падает громко, глобальный теряет всё тихо).

### B · Домен/FROZEN/канон → трёхчастно
1. SHARED.md в instructions[], но худой: домен, FROZEN («читать можно и нужно; менять — никогда»), REGISTRY=SSOT, правила веток/`_`/context7-first, «формат задаёт роль/диспатч», Реестр вердиктов. БЕЗ универсального ФОРМАТА ОТВЕТА, БЕЗ цифр канона.
2. Канон = ТОЛЬКО КАНОН-СНАПШОТ диспатча. Нет снапшота → «БЛОКЕР». Ноль цифр в статике.
3. Скиллы как носитель FROZEN/канона — отклонены (lazy-загрузка неприемлема для правила-стопа).

### C · Форматы вывода → адресная схема
- operator — статус-объект `{status, tsc, tests, changed_files[], stopped_step?, deviation?}`
- листовые исполнители — закрытый шаблон; исследователи (005/explore/general) — нумерованный markdown с источниками; судьи (002/009) — фиксированные шаблоны.
- Единый Реестр вердиктов: 002 = ДЕРЖИТ|ТРЕБУЕТ ПАТЧА|ПАДАЕТ; 009 = РЕШЕНО|ОТЛОЖЕНО|ОТКЛОНЕНО. PASS/FAIL/GUILTY запрещены везде.

### D · Энфорсмент движком → принят целиком
- edit:deny — 002, 009, explore, general, 008 (+опц. bash:deny судьям/explore)
- task:deny — всем сабам; 007 — task-glob белый список (id посимвольно = именам агентов)
- hidden:true всем сабам; subagent_depth:1 явно
- temperature: operator 0.15, 001 0.2, 002 0.2, 009 0.1, 005 0.8
- steps: explore 10, operator 25, 001 30, 002 20, 005 25, 009 12; 007 — без лимита

### E · Эскалация → близнецы `-hi`
- Авто-эскалация отклонена (невозможна без рестарта). Приняты близнецы `<id>-hi` (тот же промт-файл, .high-модель), переключение диспатчем. Стартовый набор: только 005-hi.
- Триггер: счётчик провалов роли в REGISTRY-строке; порог 2 провала или галлюцинация API при рабочем context7.
- Постоянная смена моделей = рекомендация Боссу. Кап передосудных ретраев = 2 → СТОП + человек.

### F · Гигиена применения → обязательный протокол
1. grep маркеров первых строк промт-файлов; 2. `opencode debug config` (непустые промты, permission, посимвольность task-списка); 3. старт; 4. ролевое эхо каждого агента; 5. цепной дымовой тест; кап ретраев 2.

### G · Судьба предложений Центра_5

| Предложение | Вердикт |
|---|---|
| Пер-агентное поле `instructions` | ❌ ОТКЛОНЕНО (поля нет в схеме) |
| FROZEN «NEVER read» | ❌ заменено на «read можно и нужно; modify — никогда» |
| STRICT JSON всем | ❌ заменено адресной схемой |
| XML-каркасы | форма отклонена, дисциплина сохранена (ФОРМАТ-секции в md-файлах) |
| «Think step-by-step» | ✅ ПРИНЯТО (фраза в ДОСТАВИТЬ reasoning-ролям) |
| context7-first для 005 | ✅ ПРИНЯТО |
| Авто-эскалация / петля GUILTY без капа | ❌ → близнецы + кап 2 |
| Канон в трёх местах | ❌ → снапшот-онли |
| Tier-роутинг (Kimi/DeepSeek/big-pickle замены) | ❌ противоречит цели «выжать Ox Alpha»; big-pickle неверифицируем |

### Вариант, который не предложил никто
**CHAIN-SMOKE (цепной дымовой тест)** после каждого рестарта: один диспатч 007 со спавном ВСЕХ агентов белого списка (каждый возвращает эхо роли), 009 замыкает вердиктом. Закрывает дыру: опечатка в task-белом списке молча удаляет агента из Task-инструмента, при этом юзерское @-эхо зелёное.
