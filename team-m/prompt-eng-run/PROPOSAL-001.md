```
=== DISPATCH ===

```
Принципиальные отличия от черновика U2: `{file:}` вместо несуществующего per-agent `instructions`; КАНОН-СНАПШОТ старше файла (одна точка истины за прогон); few-shot встроен в ДОСТАВИТЬ; маркер END.

## 3. ТАКТИКИ T1–T5
- **T1 Атомарность:** один вызов = один вопрос; синтез остаётся у 007.
- **T2 Few-shot обязателен:** миниатюрный образец ответа в ДОСТАВИТЬ; free-модель копирует форму почти идеально.
- **T3 Схема вместо запрета:** нумерованный положительный формат сильнее «не пиши эссе»; детерминизм структуры компенсирует недетерминизм модели.
- **T4 Канон как якорь + primacy/recency:** FROZEN первой смысловой строкой и последней строкой; ответ замыкается верификацией командой+цифрой.
- **T5 Эскалация по правилу:** два провала роли на reasoning-задаче ИЛИ галлюцинация API при наличии context7 → этот агент на `.high` (GLM-5.2/Kimi/Mimo) в opencode.json + рестарт. Один агент, не вся команда.
