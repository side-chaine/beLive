## БЛОК A · MICRO-PACK-BRIDGE-MEDIA v0.1 (голос учителя↔студента, Вып.2-3)
**Ключевые решения:**
1. **Микрофон — реестр потребителей, не клон-хозяин:** MicSourceV3 единственный владелец getUserMedia (инвариант 82e1c76), новый потребитель регистрируется → получает `track.clone()`. Рефкаунт: последний release не глушит захват, если жив питч. **Гейт: второй getUserMedia в src/ = красный CI (греп-тест, 3 строки).**
2. **Музыка по сети НЕ идёт.** Трек у обоих локально, синхронизация = существующий control-канал + VirtualClock + DriftCorrector (уже оплачено). Снимает 3 проблемы: качество/эхо/лицензии (рестрим YouTube = красный флаг). По сети — только голос.
3. **Эхо:** клон с echoCancellation:true + noiseSuppression:false + AGC:false (клоны позволяют развести констрейнты: питчу AGC мешает, голосу эхогашение нужно) · колонки без наушников → half-duplex полиси.
4. **Opus для голоса:** DTX=1 ок для речи; «пение студента по сети» = v0.2 с отдельным бюджетом — скоуп зафиксирован.
5. **Латентности-бюджет:** цель <150мс p2p / <250мс TURN (таблица по узлам в спеке, замер = Фаза 2, >30% отклонение = СТОП к 001).
6. **Голос НЕ синхронизируется с VirtualClock** — осознанно: голос = разговорный канал (мин. задержка), control = истина. «Голос с точностью доли» = ошибка архитектуры, возврат на 001.
7. **TURN обязателен** (10-20% пар за симметричным NAT/CGNAT — продукт не теряет шестой урок): CF Calls managed-TURN на v0.1, self-hosted coturn только при разрыве 3x+. **Смоук-приёмка: iceTransportPolicy:'relay' — только relay-коннект засчитывается.**
8. **Стык с onIntent:** медиа не читает транспорт НИКОГДА (события/control-канал); remote-жесты Вып.3 — через onIntent; приёмка: обходных жестов после Блока A ≤ до него.
**Фазы:** 0 греп-верификация фактов (все цифры перемерить! дерево уехало −7187) → 1 micRegistry+гейт → 2 addTrack/ontrack+SDP+латентности → 3 TURN+relay-смоук+half-duplex → 4 onIntent-стык.
**ЧЕГО НЕ СПРОСИЛ (три вопроса — ПРИНЯТО НИКИТОЙ через 200):** ① запись урока = гейт согласия Этап-2.5 до Вып.3 (двустороннее согласие) ② навсегда два (директива 09:10 анти-скоуп, SFU=Этап-3+) ③ деградация голоса = Фаза 3.5 (голос упал → урок жив по control-каналу, «учитель пишет» студенту).

## БЛОК B · MICRO-PACK-FACADE-INTENT v0.1 (D-5 фасад + onIntent)
1. **Фасад = контракт-дверь:** тонкая обёртка, НЕ дублирует состояние (никакого кэша isPlaying — второй источник истины = race №4-класс), НЕ меняет семантику (перенос жеста = бит-в-бит то же поведение). Frozen/_-поля: читать можно, трогать нельзя; невозможность через публичный интерфейс = СТОП-вопрос Центра.
2. **onIntent конвейер:** `{type:'transport.seek', payload, origin:'ui'|'remote'|'auto', ts}` — origin с первого дня (одна строка сейчас = не миграция через месяц). Один диспетчер, ВСЕ 24 обходных жеста за задачу (не постепенно!), диспетчер не валидирует бизнес-смысл (только маршрутизация+лог), intent-лог = кольцевой массив 200 записей в dev-режиме (будущий инструмент отладки рассинхрона Этапа-2).
3. **Красные гейты:** G-INTENT-1 getTransport вне whitelist = 0 · G-INTENT-2 прямой импорт транспорта = 0 · G-INTENT-3 регресс-счётчик обходных жестов (растёт = красный). Whitelist: файл с причиной-комментарием на строку.
4. **Порядок миграции:** шаг-0 пустые фасад+диспетчер (все зелёные) → по одному жесту за коммит (24 коммита, не героический) → гейты в CI ПОСЛЕ стабильного whitelist (красный-всегда гейт обучает игнорировать красное!). TC на жест пишется ДО переноса.
5. **Где сломается:** whitelist расползётся (лечение: дата+задача в комментарии, линт-варнинг на старые) · intent-лог утечёт в прод как состояние (лечение: вырезается плагином из прод-бандла, машинно) · двойной вход UI+remote в одну ms (v0.1: FIFO, Этап-2 — в Блок F).
**ЧЕГО НЕ СПРОСИЛ:** есть ли TC на все 24 жеста (если половины нет — объём ×2, знать до B-1) · кто владелец whitelist при споре (апрув 002/Центр/Никита?).
