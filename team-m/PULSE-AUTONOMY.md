## §C. КОНТРАКТ ТРИГГЕРА v2 (ФАЗА-А, немедленно)

Каждая запись в TRIGGERS/<agent>.md получает пятое поле:

```
[HH:MM] от <X> · <суть> · ТВОЙ ШАГ: <...> · ПРИЁМКА: <...> · СЛЕДУЮЩИЙ: <agent-id | НИКИТА | СТОП>
```

- `СЛЕДУЮЩИЙ: 003` — по завершении отчётом становится 003 (демон запустит его)
- `СЛЕДУЮЩИЙ: НИКИТА` — развилка 🔴, демон НЕ запускает никого, пишет в PULSE-ALERT
- `СЛЕДУЮЩИЙ: СТОП` — цепь закончена, демон логирует финиш
- Отчёт агента обязан содержать строку `ЭСТАФЕТА: <результат> → СЛЕДУЮЩИЙ: <...>` — демон парсит её

**Паттерн «СУБАГЕНТ-ЗРЕНИЕ» (стандарт с сегодня):** любой агент может: `opencode run --agent 008 "посмотри <путь-скрина>, замерь <что>"`. 008 наследует железные правила 006: клики не консоль · `[class*=]` не имена компонентов · числа со ссылкой · СТОП вместо импровизации · **скрин обязан быть с живого экрана, не с мокапа** (урок T4-инцидента).
