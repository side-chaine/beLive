# БРИФ ДЛЯ GLM (Центр_6) · beLiveBase · итерация 2 «Эфир и подземка»

## Контекст
beLiveBase — город репозитория приложения beLive. Это НЕ карта и НЕ визуализация рядом с кодом — это интерфейс кода: город читает реальный кадастр, слушает реальные события приложения и даёт управлять состоянием репо (усыпить здание, заложить чертёж, снести). Арт-система Night Stage (тихий тёмный город, тёплый янтарный свет) утверждена Боссом. База: «город молчит» — постоянных подписей нет вообще, здания говорят только по наведению, клик открывает интерьер.

## Что уже есть (не переделывать, беречь)
- Тихий город: наведение → тег-шёпот (имя + что делает), клик → осмотр здания
- Осмотр: интерьер «дом с открытой стеной», этажи = комнаты, ховер-синхрон «список ↔ свет»
- Паспорт здания: что делает / что даёт тебе / что внутри / техника / действия пульта
- Тур: цепочка остановок, камера летит по зданиям, титры lower-third, финальный CTA-кадр
- Режимы приложения (Rehearsal / Karaoke / Concert / Live) переключают свет зданий
- Шина событий: импульсы едут по линиям метро, здания вспыхивают, город шепчет
- Гейты: город не даёт снести/построить раньше срока; снос — двойное подтверждение
- Камера: колесо = зум, мышь = перетаскивание, плавные перелёты

## Что доделать — 4 блока

### 1. Режим Эфир (съёмка YouTube) — главный приоритет
- На время тура прячь всё лишнее: кнопки режимов, подсказки, бренд — остаются только город и титры
- Кинематографический letterbox: тонкие полосы сверху и снизу на время тура
- Перелёты камеры между остановками — мягче, с лёгким замедлением в конце
- Финальный кадр (общий план города + CTA) держи дольше, камера медленно отъезжает
- Цель: готовый клип без монтажа — нажал кнопку, город сам рассказал о себе

### 2. Интерьеры 2.0
- Комнаты получают характер по архетипу здания: завод — стойки и трубы, лаб — столы и светящиеся колбы, башня — этажи-полки с огоньками, площадь — прилавки. Данные комнат не меняй, меняется только рисунок
- Клик по комнате в интерьере → шёпот с её описанием (из кадастра)
- У зданий со статусом planned комнаты рисуй пунктиром: «здесь будет»

### 3. Подземка
- Маленькая тихая кнопка «метро» в углу: показывает/прячет линии метро
- Линии — едва заметные; при наведении на здание его линии загораются (уже работает) и по ним бегут импульсы
- Без легенд и подписей: кто с кем говорит — видно по импульсам

### 4. За городом и свободная земля
- Объект за дорогой (сейчас безымянный) — при наведении шёпот: «Bank_beLive — склад треков за городом»
- Верни 4 свободных участка: едва заметные пунктирные контуры без подписей; при наведении шёпот «свободная земля — ждёт своё здание»

## Жёсткие НЕТ (нарушать нельзя)
1. НЕ трогать ничего между маркерами /*CITY-STATE-START*/ ... /*CITY-STATE-END*/ и /*TOUR-START*/ ... /*TOUR-END*/ — там данные из репозитория, их перезаписывает наш генератор
2. НЕ выдумывать здания, цифры, события, тексты зданий — только то, что уже есть в кадастре CITY
3. Никаких постоянных подписей, меток, легенд — город молчит, текст появляется только по действию
4. НЕ ломать API window.beLiveBase: emit, setCadastre, inspect, tour, state, exportCadastre, journal
5. Статусы зданий читаются силуэтом и светом (пломба, забор, кран, тент), а не цветовой легендой
6. Один HTML-файл, внешних зависимостей — только шрифты

Полный HTML-файл на основе приложенного + 5-7 строк: что изменил по каждому блоку.
