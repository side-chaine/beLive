## 2. Где теряются 5–70%

Успех цепочки = `f(качество_контекста_на_входе_саба)`. Сейчас:

1. **Контекст формируется заново в каждом `task()`-вызове** руками 007. Если 007 забудет упомянуть frozen-файл — саб его не знает. Если забудет канон — саб не сверит. Это хрупко и нерепрезентативно.

4. **Скиллы не проводники:** context7 вызывается только эпизодически; прочие скиллы могут вообще не доходить до сабов.

### U3 — Выжим Ox Alpha (prompt-инжиниринг на модель)
- **Атомарность:** одна задача = один узкий запрос. «Найди все вызовы X в Y» лучше «проанализируй архитектуру».
- **Few-shot:** в промт класть 1 рабочий пример желаемого вывода (особенно для operator/009).
- **Жёсткая схема:** требовать структурированный ответ (список/JSON/дифф), не прозу.
- **007 = мозг, сабы = руки:** архитектуру/решения принимает 007 (или 001+002 adversarial), сабы делают извлечение/верификацию/применение по точному MICRO-PACK.
- **Эскалация:** если Ox Alpha дважды проваливает reasoning-задачу → переключить этот агент на `.high` (GLM-5.2/Kimi) через `opencode.json` + рестарт. По умолчанию — Ox Alpha + U1/U2.
