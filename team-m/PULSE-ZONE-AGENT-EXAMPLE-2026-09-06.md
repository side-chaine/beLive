## КТО ТАКОЙ ЗОННЫЙ АГЕНТ (одной фразой)

**Тот же 007-стиль сессия (opencode), но с ПРИВЯЗКОЙ К ЗОНЕ:** в диспатче ей говорят не «покажи мне весь репозиторий», а «твой участок — вот эти файлы B09, вот твои цифры ПУЛЬСа, следи за ними и разработай по GO».

## ЖИВОЙ ПРИМЕР · понедельник, агент-Порт заступает на смену

### 1. Диспатч 007 → агент-Порт (что получает патрульный на вход)

```
=== DISPATCH · ЗОНА B09 «ПОРТ КАТАЛОГ» ===
УЧАСТОК: src/catalog/** + src/services/upload/** (лифты zip/TG/ручная)
ЦЫФРЫ ПУЛЬСа ПО ТВОЕЙ ЗОНЕ (срез утро понедельника):
  · reach: 14 файлов твоей зоны недостижимы (из 121 общих) — твой кусок списка
  · junction: 0 нарушений по парам твоей зоны (vite-url-worker-src — чисто)
  · tsc: 190 всего, 3 ошибки в твоей зоне (TS6133 в catalog-imports)
  · churn90: 12 файлов менялись за 90 дней, hotspot: НЕТ (порт спокойный цех)
ЗАДАЧА СМЕНЫ: (а) пробежать свой кусок reach-списка, классифицировать: мусор/тест/живой-но-недостижимый (доложить класс) · (б) TS6133 в зоне — почистить по GO Оператора · (в) предложение недели: что в зоне улучшить за один коммит
ВЕРИФИКАЦИЯ: node scripts/verify-reach.mjs | grep catalog · npm run typecheck
НЕ ДЕЛАТЬ: не трогать чужие зоны, не трогать frozen-зоны, B01 и B09-стык — только доклад
=== END ===
```

### 2. Что агент-Порт делает на смене (3-4 часа)

1. **Читает свой кусок:** не весь репозиторий (это 8GB контекста!), а свои 40-60 файлов зоны. Скаут внутри зоны — дёшево.
2. **Классифицирует reach-флаги своей зоны:** «этот файл — тест, он в H-1 классе», «этот — живой, его импортирует динамический import()», «этот — мусор, вот труп» — доклад классифицирован.
3. **Меряет своё:** скорость загрузки трека (зона B01+B09 стык — его профессиональный интерес), 3 лифта: zip → TG → ручная —哪个 путь медленный и почему.
4. **Пишет блок патруля в реестр:**

```
## LOG 2026-09-07 10:xx · агент-Порт [B09] — 🛡 ПАТРУЛЬ СМЕНЫ
- reach-кусок зоны: 14 флагов → 11 тесты (H-1) · 2 живые (dynamic import, доклад 007) · 1 мусор (kandidat на снос, ждет GO)
- TS6133 зоны: 3 → 0 (коммит по GO Оператора, канон 190→187)
- Лифты: zip 4.2с · TG 3.8с · ручная 6.1с → ручная медленнее на 45%, причина: двойной парсинг
- Предложение недели: унифицировать парсер лифтов (1 коммит, −80 строк)
```

### 3. Чем это ОТЛИЧАЕТСЯ от того, что есть сейчас

| Сейчас | С зонным патрулём |
|---|---|
| 007 одна смотрит ВСЕ 121 reach-флагов | агент-Порт смотрит свои 14, агент-Завод свои 30, агент-Sync свои 8 — параллельно, каждый эксперт своей зоны |
| Скауты тратят контекст на весь репо | скаут зоны читает 50 файлов, не 800 |
| Вопросы «кто знает, почему этот файл жив?» | у каждого файла есть дом → у каждого дома есть патрульный |
| ПУЛЬС меряет, но «чтение диагноза» — вручную | агент зоны читает свои цифры каждый понедельник + на каждый алерт своей зоны |
| Разработка идёт от хаба ко всему | каждая зона может предложить свою «разработку недели» по GO |

### 4. Что НЕ меняется (важно!)

- **Гейты ПУЛЬСа уже общие и остаются общими** — патруль не заменяет их, он ЧИТАЕТ их вывод среза по своей зоне.
- **Прод-код — по-прежнему только Оператор через цепь.** Патрульный мониторит и предлагает, не правит сам.
- **Реестр/триггеры — прежние.** Агент-Порт пишет обычный LOG-блок, просто с меткой зоны.
- **007 остаётся главным диспетчером:** она режет reach-список по зонам и выдаёт диспатчи. Не новый уровень иерархии — новая специализация.

### 5. Каркас запуска (что сделает 007 по GO)

1. **Мэппинг зон:** файл `team-m/PULSE-ZONES.yaml` — зоны из списка Никиты → пути в src → дома кадастра (B01/B02/.../B09/B08) → slice-фильтры для гейтов (reach --zone=B09).
2. **Флаг `--zone` в гейтах ПУЛЬСа:** verify-reach/inert/junction печатают срез по зоне (малая правка, носитель — существующие скрипты).
3. **Промпты агентов:** `.opencode/agent/port.md`, `factory.md`, `sync-tower.md` и т.д. — по одному на зону (только что собранные: участок + правила + формат доклада).
4. **Расписание смен:** не жёсткий таймер (проверяли — жрёт контекст), а **диспатч 007 по триггеру** (раз в смену + на алерт зоны).

**Порядок наращивания:** начнём с ДВУХ пилотных зон — **агент-Порт (B09)** и **агент-Башня-Sync (B08)** (ты просил полный разбор Sync — это самый богатый фронт). После двух смен пилота — раскатка на остальные зоны.
