## Формат строки (жёсткий, одна строка = один шаг)

```
[HH:MM] от <кто> · <что готово> (<коммит>) · ТВОЙ ШАГ: <действие>
        · СПЕКА: <где читать> · ПРИЁМКА: <команда → ожидаемое>
```

## Правила

1. **Пишет ТОТ, КТО РАЗБЛОКИРОВАЛ.** Закончил шаг, от которого зависит другой агент → одна строка в его файл. Не «когда вспомнишь» — сразу после гейтов.
2. **Читает владелец файла при каждом `00`** — первым делом, до реестра.
3. **Исполнил → строку не удаляешь, помечаешь `✅ взято HH:MM`** и дописываешь свою новую (история хода видна).
4. **Файл держим коротким:** >10 строк — старые в `TRIGGERS/archive/`. Чистит 200.
5. **Триггер ≠ приказ на код.** Прод-код по-прежнему только Оператор через 007/007-YT; 🔴-решения только Никита.
6. **Пустой файл — легальное состояние.** «Ждём» — тоже ответ, писать вслух в реестр не нужно.
