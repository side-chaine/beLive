## §1 V2-контракт vs v3-реальность

Публичная поверхность V2 (из frozen AudioEngineV2.ts + patchV1.ts): transport (play/pause/stop/seekTo/setCurrentTime/getCurrentTime/getDuration), volume (setStemVolume/setStemMute/setStemSolo/toggle*/getStemVolume/setInstrumentalVolume/setVocalsVolume/setMicrophoneVolume/**setBusVolume/getBusVolume**), routing (getBusGainNode/getActiveBusIds/getBusStemIds), metering (getStemMeterLevel/getStemAnalyser), buffers (getStemAudioBuffer/getStemSourceNode/getVocal*/ensure*Buffer), loop (setLoop/clearLoop + getters), mic (enable/disable/toggle/getState/getStream), vocalMix (enable/disable/toggle/getState), rate (set/getPlaybackRate), capture (captureStream❗dep/getProgramCaptureStream/attach|detachProgramSource/setCaptureMicEnabled❗dep), loading (loadTrack/loadAdditionalStems/setStemsEnabled/awaitStemReady), events (onTrackLoaded/onPositionUpdate/onBothEnded/removeEventListener), props (duration/isPlaying(get+set!)/audioContext/hybridEngine/stems Map/microphone*/streamDestination/instrumentalGain/vocalsGain/*Audio).

Дрейф контракта: `IV2PublicContract.ts` декларирует то, чего в frozen V2 **нет** (`setStemPan`, `setStemsMode`), и не декларирует то, что в V2 **есть** (`setBusVolume`, `getBusVolume`, `getProgramCaptureStream`, `awaitStemReady`, `getDuration`, mic-state…). Плюс `delegateSync` использует optional-call `(v2 as any)[method]?.(...)` (V2Adapter.ts:57) → отсутствие метода = **молча** undefined, не ошибка.

## Топ-5 для MIGRATION-HOLES сводки

1. **P1 · Silent no-op как дизайн API**: `delegateSync` optional-call (V2Adapter.ts:57) + фантомные методы контракта (`setStemPan`/`setStemsMode` в IV2PublicContract/PUBLIC_METHODS отсутствуют в frozen V2) → целые фичи (pan) умирают без единого лога. Класс B-slice, масштабируемый: каждый новый метод в whitelist без реализации в V2/facade — новая тихая дыра.
2. **P1 · «solo не solo» воспроизведён в v3**: take-preview solo-mute (useTakesPlayback:51-52) глотается mini-gard'ом → движок играет поверх превью; restore льёт stale store-значения (E5-семейство).
3. **P2 · Whitelist ≠ реальность в обе стороны**: `setBusVolume` есть в V2, нет в whitelist (v2 bus-фейдеры мертвы); `getProgramCaptureStream`/`awaitStemReady`/mic-state — вне контракта, консьюмеры legacy-папки уже падают тишиной.
4. **P2 · Event-surface v3 неполн**: microphone/vocalmix/playback-rate(document)/track-stem-ready/track-fully-loaded в v3 не эмиттятся → store/UI дрейфует от графа; канонический пример — 🎤-тумблер врёт после переключения в v3.
5. **P2 · Program-capture без хозяина в v3**: V2-bus замолжен cage, router.captureStream никто не потребляет, preview-источники подключаются «в никуда» записи — до первого «пустого файла записи» репетиции.
