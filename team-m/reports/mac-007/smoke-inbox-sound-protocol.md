# Smoke «правка INBOX → звук»: протокол (Mac готов; первая попытка убита падением монтажа)

## Условия
- Mac: Node ОТСУТСТВУЕТ (проверено: нет node/npm/nvm/volta/bun) → dev-сервер на Маке невозможен. Роль Мака = триггер правок через sshfs (подтверждён: fuse-t:/beLive-PC, ремоунт после инцидента).
- PC: V007 поднимает `npm run dev` в /home/nikit/projects/beLive, открывает приложение.

## Механика триггера
Каждый запуск `team-m/scripts/mac-state.sh` меняет строку `_Обновлено:` INBOX → новый djb2 `len:h` → поллинг 1500ms → dispatch → ожидаем звук 880→1760 + аватар happy.

## Шаги
1. V007: dev-server + браузер → «ГОТОВ» в канал.
2. Mac: пауза 5с → прогон mac-state.sh (= правка INBOX).
3. Наблюдение 3–5с: звук + аватар.
4. Контроль-ноль: повторный прогон тоже меняет timestamp → ВТОРОЙ диспатч (dedup по хэшу, не по времени).
5. Анти-тест: touch без изменения байтов НЕ диспатчит (хэш тот же).

## Критерий PASS
Оба диспатча прозвенели, ложных нет, `notify.store.lastHash` совпадает с хэшем файла.
