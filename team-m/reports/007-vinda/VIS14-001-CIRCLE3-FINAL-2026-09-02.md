## 🔴 БОССУ (3 решения, обновлённые по 002-⑥)
1. **Выбор релиза:** правило пака §2 [У5] как канон ДО прогона: C дефолт ⇔ C≥A+2пп бас/гроул И C≥A−1пп чистый (чистая конъюнкция, «ничья» вычеркнута — иначе A). **Обязательное условие при победе C:** микропак проводки включает ЛИБО worklet-близнец C, ЛИБО feature-гейт «mic остаётся на A» + скрытие isMatch (`PitchTab.tsx:338`) при детектор-миксе — иначе двухголовый прод (vocal=C, mic=A, octLock-расхождение `yin-detect.ts:163-172` vs `yin-processor.js:176-183`).
2. **AB-тестирование:** пользовательское A/B НЕ проводить. Смоук-неделя = чек-лист сценариев (гроул, фальцет, бас, вибрато, шёпот) + критерий отката: любой live-брек C (аналог brokeByC на слух/записи) → A без обсуждения.
3. **Исследование X (FFT-difference):** спека готова (zero-pad 2N−1, кэш планов, running-sum E(τ)); рождается С инвариантом «FFT-CMND ≡ direct-CMND» (допуск ~1e-6, механизм PV-6) — иначе третий источник правды при уже живом расхождении yin-detect↔yin-processor. dYIN — вне (запрет диспатча).
