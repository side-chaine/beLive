## 0. РЕШЕНИЕ (суть)

Индивидуальный снапшот голоса = **пассивный слушатель существующего питч-канала** + **один WaveShaper-фейдер на мик-стриме** + **молчаливая запись кадров в localStorage**. Ноль нового DSP: YIN-метрики, SFM, MicSourceV3, R9 — всё живо и уже в проде. Новый код = 4 файла (сервис, DSP-цепь, стор, экран) + 2 тест-файла. Наука (Kalbag&Lerch: типы скримов 45% — не разделяются) → никаких классификаторов: снапшот = точка отсчёта конкретного пользователя, не приговор.

### ③ Фейдер-цепь WaveShaper (мик-граф)

**Новый файл `src/audio/voice/split-fader.ts`** — класс `SplitFaderChain`.

**Граф (всё на ctx из `__belive.pipeline.ctx` — `HybridPipelineService.ts:135`):**
```
MicSourceV3.acquire() → createMediaStreamSource → highpass(80Hz) → lowpass(2000Hz)
  → [dryGain ─────────────┐]
  → [WaveShaper → wetGain ─]→ outGain → destination
```
- **Кривые:** `clean` = identity (tanh-soft на 0.0), `distorted` = жёсткий tanh-сатуратор (расщеп-подобная гармонизация). `setMix(x: 0..1)`: `curve[i] = lerp(clean[i], distorted[i], x)` + `dryGain=1−x`, `wetGain=x` (equal-power: `cos/sin` по √2). Интерполяция кривой — на input-событие фейдера, не на кадр (дешево).
- **R9-совместимость:** стрим уже открывается с `{echoCancellation:false, noiseSuppression:false, autoGainControl:false}` (`MicSourceV3.ts:73`) — цепь ничего не добавляет, только читает тот же стрим через refcount (`acquire():33-47` / `release():50-53`). PitchEngine-мик (worklet-путь `pitch-engine.ts:110-130`) висит на том же стриме параллельно — два `createMediaStreamSource` на одном MediaStream легальны, mic-race исключён by design (инвариант 82e1c76).
- **Audible-feedback (игра):** пользователь СЛЫШИТ свой голос с градусом расщепа = фейдер. Это ядро концепции Никиты («водит фейдер и СЛЫШИТ, как меняется нота»).
- **Анти-петля (feedback-гвард):** `outGain.gain.value = 0` по умолчанию; включается только кнопкой «🎧 монитор» в VoiceCalibration (наушники). Дефолт = тихая калибровка (метрики пишутся, звука нет). G14/MonitorRouter.micInput НЕ трогаем (F-2 — будущий маршрут, v0 не ждёт его).
- **Dispose:** `release()` стрима + disconnect всех узлов (паттерн `pitch-engine.ts:240-282`).
