## ОТВЕТЫ НА 6 ВОПРОСОВ ПАКА
- **① position-гейт:** в стенд-сервисе (③), НЕ в PitchEngine и НЕ в PitchTab-рендере. Гейт = окно [lo,hi]сек; в v1 — таймлайн мока (кадр×46ms), в v2 (live-тап, если будет) — ctx.currentTime. Атомарность тик→гейт→счёт в одном месте; PitchTab только задаёт окно и читает snapshot. Если выбор строго двоичный — PitchEngine (там timestamps), никогда React (ре-рендер ≠ аудио-время).
- **② vision-измерение:** Audacity — только ручной sanity-кросс-чек 1-2 стем-кейсов оператором; основное = автоматика (CREPE-JSON для стемов, аналитический ref для моков, per-frame timestamps в JSON). **digitalClock-vs-Dispatch отвергнут**: меряет UI-синхронизацию дисплея, не детекцию — вторая измерительная система = лишняя часть.
- **③ выборки A/B:** парный дизайн — все 3 контура на ОДНИХ кадрах (per-frame pairing), frame-pooled агрегация [У3], warm-up exclusion [У2], валидность ≥300 voiced-кадров. Никакой случайной/послойной выборки — смещение запрещено.
- **④ был/стал счётчики:** парные per-frame vs ref (|cents|>50 = ложь): `aLies, cLies, fixedByC (aLie∧¬cLie), brokeByC (¬aLie∧cLie)`. «Был/стал» = fixedByC/brokeByC. Считает стенд-сервис, показывает vignette, пишет JSON. Гроул — только Chroma-счётчик [У6].
- **⑤ signage:** чипы в стиле S.btn/S.label (PitchTab.tsx:26-63): `A·YIN / B·MPM / C·vote`, `ref: C4`, детект per-contour `✓/✗`, `A-лжи 12 → C 2`, `0.8ms/f`. Заголовок `🔬 pitch-stand (dev)`. DEV-only, без i18n, без store. Плашка «sanity, not verdict» — моки не вердикт.
