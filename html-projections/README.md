# 🎞 HTML-проекции beLive (ПК)

Это папка, куда **агенты кладут визуальные «проекции»** — самодостаточные
HTML-файлы, объясняющие что-то Никите наглядно (схемы, метафоры, дашборды).

## Правила для агентов
1. Файл должен быть **самодостаточным**: весь CSS и JS — inline внутри `.html`
   (без внешних ссылок, картинок, шрифтов). Тогда он откроется где угодно.
2. Клади файл сюда: `html-projections/<kebab-name>.html`
   (например `system-overview.html`, `character-ai-flow.html`).
3. После создания просто доложи Никите: «готово, запусти».

## Как Никита смотрит
Команда `proj` (добавлена в PATH):
- `proj`            — открыть **самую свежую** проекцию в браузере
- `proj list`       — список всех проекций с номерами
- `proj <n>`        — открыть проекцию № n из списка
- `proj <имя>`      — открыть `html-projections/<имя>.html`
- `proj gallery`    — открыть кликабельную галерею всех проекций

Проекции копируются во временную папку Windows и открываются в браузере
по умолчанию — независимо от путей WSL.

## Текущие проекции
- `system-overview.html` — метафора работы ПК ⇄ Мак (мост, доска статуса,
  почтовый ящик, дверной звонок).
- `migration-dashboard.html` — визуальный War Room миграции V3→M3-GO: хребет
  станций, счёт Вёдра 2:0 Задроты, следующие шаги, тесты/логи, автоматизация.
