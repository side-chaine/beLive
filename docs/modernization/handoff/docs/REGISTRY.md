### 4.1 Находки в коде (findings)

Здесь лежат **конкретные разобранные баги и элегантные решения** — то, что найдено
при разборе отдельных частей кода, а не при планировании. Это раздел под запрос
Никиты: *«если видишь лучше, интереснее, элегантнее решения — фиксируй для 007»*.

| Finding | О чём | Статус | Эффект |
|---|---|---|---|
| [FINDING-001](./findings/FINDING-001-v2-resurrection-detector-silent-noop.md) | `V2ResurrectionDetector` не мог измерить ничего: `require()` в ESM, неверный путь, чтение несуществующих полей, метод из одних комментариев | ✅ исправлено | `tsc` 216 → 212, `TS2591` → 0; monkey-patching заменён на `V2Adapter.observe()` |
| [FINDING-002](./findings/FINDING-002-audioworklet-realm-typing.md) | 80 ошибок в `CaptureWorklet.ts` — не долг по типам, а отсутствующие декларации AudioWorklet-realm'а | ✅ применено | `tsc` 307 → 227 одним `.d.ts`; ноль правок рантайма. Плюс почему **нельзя** тянуть `@types/node` в браузерный проект |

**Паттерн из FINDING-001, который стоит запомнить 007:**

1. `eslint-disable` + пустой `catch {}` **одновременно** — это не стиль, это выключенный детектор. Компилятор кричал (`TS2591`), его заставили молчать вместо того чтобы послушать.
2. Наблюдение через подписку у choke-point (`V2Adapter.observe()`) всегда лучше monkey-patching чужого инстанса: нечего восстанавливать, нечего забыть, нечего сломать.
3. `(obj as any).getState?.()` — это `as any` как способ отключить реальность. Существование API проверяется grep'ом, а не надеждой.
4. Комментарий, обосновывающий кривое решение («avoid circular dependency»), может быть **выдуманным** — проверяй рёбра импортов.

1. **Все изменения аддитивные.** Создавай новые файлы, правь конфиги. Не трогай чужую незакоммиченную работу.
2. **Не пушить без GO.** Явного разрешения Никиты.
3. **Каждое число — фактом.** Если не измерял — пиши `[НЕ ПРОВЕРЕНО]`, а не копируй из старого отчёта. В этой сессии два унаследованных числа оказались неверны: «канон 296» (реально 307) и «belive-api потерян» (реально отдельный репозиторий).
4. **Если нашёл ошибку в своём же прошлом отчёте — исправь его, а не только напиши новый.** Так в baseline появились маркеры ⚠️ и явное исправление §2.3.
5. **Обновляй этот реестр** после каждой волны: метрики, статусы ADR, карту документов.
