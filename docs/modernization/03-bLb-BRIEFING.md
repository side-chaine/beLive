## Что я придумал и зачем

У вас **уже есть** куски bLb, но они не сшиты:

- **Город-метафора** (Мак и Босс) — концепция без файлов.
- **Агентский реестр** `.opencode/agent/` (001/002/005/007/008/009) — агенты **процессные**, не привязаны к коду.
- **`DOMAIN-OWNERSHIP.yaml`** (22 домена) — владельцы строкой, не живой сущностью.
- **Скриншоты UI** — есть 51 штука в `OneDrive/Изображения/Screenshots`, не связан с репо.
- **YouTube-визуал** (цель Босса) — нет ничего, что можно показать, кроме «вот код».

**bLb (beLiveBase)** = шов между этими слоями + название + правила. Обещания:

1. Документация = код. Тыкаешь в здание → читаешь его `BUILDING.md`. Меняешь код → CI блокирует PR с устаревшим паспортом.
2. У каждого района свой лёгкий агент (DeepSeek V4 Flash). Мониторит зону, тянет Context7, пишет инициативы в `INBOX.md`.
3. Здание = файл = этаж = ютуб-туровый объект.
