## 0. Что изменилось в эту сессию

Предыдущая версия роадмапа начиналась с W1 «Типы». **Это была ошибка приоритизации.**

Переснятие baseline вскрыло: **проект на Windows не собирается и не тестируется.** В `node_modules` — Linux-бинари, `node_modules/.bin` не содержит ни одного `.cmd`-шима, из шести npm-скриптов работает один. Причина — каталог синхронизируется через OneDrive между машинами с разными ОС.

Отсюда каузальная цепь, объясняющая всё остальное:

```
node_modules приехал с Linux → npm-скрипты мертвы → локальной обратной связи нет
   → проверка только в CI → в CI НЕТ шага typecheck → 307 ошибок не видит никто
   → «канон 296» становится фольклором → никто не чинит невидимое
```

**Поэтому добавлена волна W−1.** Требовать «ноль ошибок tsc» от машины, которая не может запустить `tsc`, бессмысленно.

**Ещё два открытия, поменявших план:**
- Репозиторий **публичный** → внутренние доки загитignoreны **осознанно**; «быстрое исправление gitignore» обернулось бы утечкой. Нужны два репозитория ([ADR-0011](./ADR-0011-git-and-doc-visibility-policy.md)).
- Из 61 «устаревшего пакета» 36 — мусор в манифесте. Реальный тулчейн-долг — **7 мажоров, а не 44** ([ADR-0012](./ADR-0012-dependency-manifest-policy.md)).

## 3. Волны (порядок критичен)

```
W−1 ОЖИВИТЬ МАШИНУ ──▶ W0 ГИГИЕНА ──▶ W1 ТИПЫ (MISSION ZERO) ──▶ W2 ЛЕГАСИ-KILL ──▶ W3 РАНТАЙМ ──▶ W4 ТУЛЧЕЙН
      (дни)              (1 нед)          (4–6 нед)                (3–4 нед)         (2–3 нед)      (2 нед)
                                                                                                       │
                                              W5 АРХИТЕКТУРА ─────────────────────────────────────────┘
                                                 (6–8 нед, параллельно W3–W4)
```

**Почему именно такой порядок — четыре правила:**

0. **Среда раньше всего (W−1 → W0).** Гейт, который нельзя прогнать локально, соблюдаться не будет. Сначала делаем проект запускаемым, потом требуем от него качества.
1. **Типы раньше легаси (W1 → W2).** Удалять 2 178 строк замороженного движка при 541 `as any` — слепая хирургия. Сначала рентген.
2. **Легаси раньше тулчейна (W2 → W4).** Апгрейд TS 5.9 → 7.0 на коде, где ещё жив V2, означает чинить две эпохи одновременно.
3. **Тулчейн раньше архитектуры (W4 → W5).** TS 7 ускоряет проверку ~10× — decomposing god-файлов без быстрого фидбека мучителен.
