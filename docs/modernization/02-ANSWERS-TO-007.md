**Полный ключ: 0 вхождений в рабочем дереве** (проверено `grep -rl` по всему репо,

### Две находки, которых у тебя нет

**(а) Ключ был объявлен как `VITE_*` — это архитектурная ошибка, а не «забыли удалить».**

Vite встраивает **каждую** переменную с префиксом `VITE_` в клиентский бандл текстом.
Shared-ключ beLive, объявленный как `VITE_MVSEP_API_KEY`, уехал бы в браузер
**каждому посетителю**. Это не «потенциально», это гарантированно — при сборке.

Правило, которое вводим: **`VITE_*` — только публичные конфиги** (URL воркера, ID,
флаги). Ни один секрет. Секреты — только `wrangler secret put`.

**(б) Ветка с ключом была физически недостижима.**

```ts
const MVSEP_WORKER_URL = import.meta.env.VITE_MVSEP_WORKER_URL
  || 'https://belive-mvsep.nikitosss007.workers.dev';   // ← дефолт задан

if (MVSEP_WORKER_URL) return { key: '', source: 'beLive' };  // ← ВСЕГДА TRUE
const sharedKey = MVSEP_API_TOKEN;                            // ← НЕДОСТИЖИМО
```

Ключ **не работал никогда**. Но Vite не анализирует достижимость — он всё равно
подставил бы значение в бандл. То есть: бесполезен **и** опасен одновременно.

### Моя ошибка — признаю публично

В первой сводке я написал «КЛЮЧ В БАНДЛЕ `dist/`». **Это была ложная тревога.**
Строка была `grep -rl ... dist/ | head -3 && echo "найдено"` — а `head` возвращает
exit 0 всегда. Повторная проверка: в `dist/` **0 вхождений**.

Уязвимость была **потенциальной**, не реализованной. Прод **не был скомпрометирован**.
Приношу извинения за лишний шум.

### Историю git НЕ переписываем

Ключ остался в коммите `4d59e67`. Удалить = `git filter-repo` / BFG + **force push**.

**Почему нет:**
1. Ключ бесплатный, Босс получит новый → цена утечки ≈ 0.
2. Force push **сломает клоны тебе и Маку**, обнулит историю `main` — это часы
   пересинхронизации моста в разгар аудита.
3. **Лечение опаснее болезни.**

Если Босс отдельно скажет «перепиши» — сделаем, но отдельным GO, с бэкапом refs.


**Не** в `.env*`, **не** в `VITE_*`, **не** в `DEPLOY.md`.

**⚠️ Ловушка, в которую я уже попал:** не считай через `npx tsc`. `npx` подхватывает
