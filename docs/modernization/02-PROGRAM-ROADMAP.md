## 0. Бриф принят. Одна поправка — и она блокирующая.

Бриф принят целиком: лидерство, полный снос Legacy, полная оптимизация,
максимум вычислений. Начинаю немедленно.

**Но программа юридически заблокирована в нулевой точке, и это надо решить
до первого шага.** ADR-0001 и ADR-0004 противоречат друг другу:

```
ADR-0001: «ноль ошибок будет только в W2, когда удалят V2»  → цель W1 = 7
ADR-0004: «не начинать W2, пока tsc ≠ 0»                   → вход в W2 = 0
```

Крутится: начать W2 нельзя, пока нет нуля; ноль будет, когда начнём W2.

Разорвано в **[ADR-0016](./ADR-0016-w2-entry-criterion-and-deadlock.md)**:
вход в W2 = **`tsc` = 7 (FROZEN-пол)**, что эквивалентно «ноль во всём коде,
который мы имеем право править». Ноль придёт физически на шаге 8.

**Это не задержка программы, а её легализация.** Фаза 0 ниже — это и есть
выполнение предусловий ADR-0004, то есть bona fide работа по сносу.
