# ADR-0012 · Политика манифеста зависимостей: в `package.json` только то, что импортируется

**Статус:** proposed · **Дата:** 2026-08-29 · **Волна:** W0 (блокирует [ADR-0005](./ADR-0005-toolchain-upgrade-path.md))
**Связано:** [01-BASELINE §5.2](./01-BASELINE.md)

---

## Контекст

`devDependencies` содержит **86** пакетов. Классификация скриптом (по реальным `import`/`require` в `src/`, `scripts/`, `gateway/`, `belive-feed-bot/`, `js/`, `public/`, конфигах; `package.json` исключён как самореферентный):

```
devDependencies total : 86
реальные инструменты  : 23
НЕ УПОМИНАЮТСЯ НИГДЕ  : 63
```

**63 пакета числятся прямыми, но нигде не импортируются.** Это транзитив eslint/ajv/js-yaml, который попал в манифест:

```
minimatch  chalk  ansi-styles  brace-expansion  find-up  p-limit  flat-cache
estraverse  levn  optionator  espree  esquery  esrecurse  esutils
fast-deep-equal  fast-levenshtein  json-schema-traverse  uri-js  punycode
which  cross-spawn  shebang-command  isexe  supports-color  has-flag  …
```

**Первый вред — технический.** Прямые зависимости **навязывают версии всему дереву**:

| Пакет | Закреплён как прямой | Хочет современный eslint | Разрыв |
|---|---|---|---|
| `minimatch` | `^3.1.2` (2019) | `^10` | **7 мажоров** |
| `brace-expansion` | `^1.1.12` | `^5` | 4 мажора |

npm разрешает конфликт, устанавливая **обе** версии — одну для eslint, одну «прямую». Дубли в дереве, непредсказуемая резолюция, раздутый `.package-lock.json`.

**Второй вред — управленческий, и он хуже.** «61 устаревший пакет, 44 мажора» — это число, глядя на которое апгрейд тулчейна откладывается «до лучших времён»:

| Метрика | Как выглядит | На самом деле |
|---|---|---|
| Устаревших | 61 | 25 |
| Мажоров | 44 | **7** |

**Задача «обновить 44 мажора» выглядит как квартал и не начинается никогда. Задача «обновить 7» — это два вечера.** Манифест создаёт ложную картину долга, и именно поэтому его чистка — первая, а не последняя.

---

## Решение

### 1. Вынести 63 транзитивных пакета из `devDependencies`

Оставить **23** реальных инструмента:

```
typescript  vite  vitest  eslint  @eslint/js  @typescript-eslint/*
@playwright/test  @vitest/ui  jsdom  @testing-library/react
@testing-library/jest-dom  @types/react  @types/react-dom  @types/jszip
vite-plugin-pwa  vite-tsconfig-paths  workbox-window  globals  ajv  js-yaml
acorn  acorn-jsx  lodash.merge  (уточнить при исполнении)
```

Процедура: `npm uninstall <pkg>` для каждого из 63 → `npm install` → прогнать канон. Удаление безопасное**: транзитив никуда не исчезнет, npm продолжит ставить его как зависимость eslint — просто больше не навязывая версию сверху.

### 2. Запрет на повторение: проверка в CI

```bash
# scripts/check-manifest.mjs — красный свет, если прямая зависимость нигде не импортируется
node scripts/check-manifest.mjs
```

Правило простое: **пакет в `dependencies`/`devDependencies` обязан встречаться в `import`/`require` где-то в исходниках** (исключения — белый список: `globals`, `jsdom`, типы, плагины, подключаемые строкой в конфиге).

### 3. Три правила на будущее

| Правило | Формулировка |
|---|---|
| **Прямая — только импортируемая** | Если не `import`'ишь — не добавляй в манифест. Пусть приедет транзитивом |
| **Один мажор — один PR** | См. [ADR-0005](./ADR-0005-toolchain-upgrade-path.md) |
| **Lockfile в git, всегда** | `package-lock.json` коммитится. `npm ci` в CI, не `npm install` |

### 4. Разобраться с `ajv@6`

Единственный пакет из списка, который **одновременно** устарел на 2 мажора и **security-relevant** (ajv 6 имеет известные проблемы с prototype pollution при определённых схемах). Проверить, кто его реально использует:
- если это транзитив старого eslint → убрать из манифеста (решение №1);
- если используется для валидации схем в своём коде → **отдельный PR на ajv 6 → 8**, приоритетно, вне общей цепочки.

## Почему не другие варианты

| Вариант | Почему нет |
|---|---|
| Оставить как есть, «работает же» | Ложная картина долга блокирует [ADR-0005](./ADR-0005-toolchain-upgrade-path.md). Число 44 мажора парализует решение об апгрейде |
| Просто запустить `npm update --latest` | Обновит и мусор тоже; две трети работы впустую плюс риск сломать eslint |
| `npm prune` | Убирает неописанные пакеты, но **не** правит манифест. Проблема останется |
| Перенести всё в `dependencies` | Усугубит: мусор поедет в прод-бандл |
| Дождаться W4 и чинить там | К тому моменту придётся обновлять 44 мажора вместо 7 |

## Последствия

**Плюсы**
- Манифест становится **читаемым**: 23 строки вместо 86. На вопрос «какие у нас инструменты» можно ответить, глядя на файл.
- Схлопывается картина долга: 61 → 25, мажоров 44 → 7. Апгрейд перестаёт выглядеть как квартал работы.
- Уходят навязанные старые версии (`minimatch@3`) → меньше дублей в дереве.
- CI-проверка превращает разовую чистку в **постоянный контроль**.

**Минусы / чем платим**
- **63 строки diff.** Механическая, но большая правка. Риск: случайно удалить нужное. Компенсация: удалять пачками по 10, после каждой — прогон канона.
- **Белый список исключений.** Некоторые пакеты нужны, но не импортируются явно (`jsdom`, `globals`). Компенсация: явный белый список в скрипте проверки, изменение ревьюится.
- Классификатор по `import` может ошибиться на динамических импортах. Компенсация: после чистки — полный прогон `npm run build`, он покажет, если что-то действительно нужно.

## План внедрения

| Шаг | Действие | Проверка |
|---|---|---|
| 1 | Скрипт `scripts/check-manifest.mjs` + белый список | выдаёт ровно 63 |
| 2 | `npm uninstall` пачками по 10 (6 пачек) | после каждой: `npm run build` |
| 3 | Финальный `npm install` | lockfile обновлён |
| 4 | Прогон канона | `typecheck` = 307 (не вырос), `test`, `build` |
| 5 | Шаг проверки в CI | гейт зелёный |
| 6 | Обновить метрики в REGISTRY | `npm outdated` → ≤25, мажоров ≤7 |
| 7 | Разобрать `ajv@6` отдельно | либо удалён из манифеста, либо обновлён до 8 |

**Откат:** `git checkout package.json package-lock.json && npm ci`. Полностью обратимо.

---

## Критерий успеха (DoD)

- [ ] `devDependencies` ≤ **30** строк (цель ~23)
- [ ] `npm outdated` → ≤ **25** пакетов, из них мажоров ≤ **7**
- [ ] `npm run build` собирается
- [ ] `tsc --noEmit` = **307** (не вырос — чистка не сломала типы)
- [ ] CI-гейт `check-manifest` зелёный

> **Ключевой критерий — не «стало меньше строк», а «картина долга стала правдивой».** После этой волны фраза «у нас 44 мажора» должна стать исторически неверной.
