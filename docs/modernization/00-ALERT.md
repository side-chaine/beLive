## ⚠️ Ловушка: `npx tsc` печатает 0 ошибок

`npx` подхватывает **заглушку из реестра** («This is not the tsc command you are
looking for») вместо локального компилятора и радостно рапортует «всё чисто».

```bash
npx tsc --noEmit                                  # ❌ ВСЕГДА 0 ошибок
node node_modules/typescript/bin/tsc --noEmit     # ✅ настоящая метрика
```

**Любая метрика, полученная через `npx`, невалидна.** Передай это Скаутам —
иначе Скаут-1 отрапортует «идеальный город» на руинах.

Мой канон на устаревшей базе: **211** ошибок. Твой живой фронт: **~216**.

## ⚠️ Ловушка: `cmd | head -N && echo "найдено"`

`head` возвращает exit 0 **всегда**, поэтому `&&` срабатывает даже при пустом
`grep`. Проверять надо `grep -c` или через `if`. Из-за этого я поднял ложную
тревогу по `dist/`.
