## 2. Метафора: репозиторий как город

Держите её в голове, она делает отчёты сопоставимыми:

| Город | Репозиторий |
|---|---|
| Район | модуль / директория (`audio`, `stores`, `takes`) |
| Здание | файл |
| Коммуникации (вода, свет) | импорты — кто от кого зависит |
| Электростанция | hub — файл, от которого зависят десятки |
| Трущобы / заброшки | orphan — никому не нужный код |
| Круговой перекрёсток без выезда | цикл импортов |
| Кадастровая палата | этот аудит |
| Стройнадзор | CI-гейты |
| Паспорт объекта | документация модуля |

**Правило города:** сносить можно только то, что отключено от коммуникаций.
Если из трущоб идёт кабель в больницу — это не трущобы, а инфраструктура.

## 8. Правила игры

- **Читай, не пиши.** (правило номер ноль)
- **Указывай HEAD.** Любой отчёт без SHA базы недействителен.
- **Не доверяй своей базе.** Перед стартом: `git fetch && git log -1 --date=short origin/main`.
  Сравни `git rev-parse origin/main` с `git ls-remote origin main` — если
  расходятся, указатель застрял в `packed-refs`.
- **Секреты — только маскированные.** Первые 6 символов, не больше.
- **Сомневаешься — в отчёт, не в решение.**
