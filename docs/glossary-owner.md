# ГЛОССАРИЙ: СЛОВА ВЛАДЕЛЬЦА → КОД (beLive)

> Источник: 008 VISUAL-MAP (VMO-001…040, 2026-08-26). Золото для склейки агент-команд с кодовой базой.
> Правило: слово владельца СТАРШЕ догадки агента. При расхождении — фиксируй оба.

| Владелец | Код/сущность | Где искать |
|---|---|---|
| Трек-мэп / Wagon Train / «вагоны» / блоки | Структура секций трека (TrackMap) | `src/**/track-map*` |
| Плашка | Центральная панель лирики (док) | `ai-chat-ui` / `plates` |
| Фейдеры Inst (красный) / Voc (синий) | Два главных регулятора; **Inst = мастер-группа музыкальных стемов** | `src/audio/**` |
| B/P/M в доке | Режимы темпа (P = проценты −5/+5; B и M — уточнить у владельца) | сценарии/Quest |
| I/V/M | Инструментал / Вокал / Микс (в Quest-волне) | `useTakesPlayback` |
| FULL / DUO | ZIP 7 стемов / вокал+инструментал; Toggle Stems переключает загрузку | `catalog/upload` |
| ПОРТ | Дроп-зона .zip в каталоге | `catalog/port` |
| Lines | Модалка версий lrclib | `sync-editor` |
| Blocks | Редактор блоков (легаси до lrclib) — аудит нужен | `block-editor` |
| Сценарий блоков / Background | Редактор сцен: фон на каждую строку; Upload Pack | `background-editor` |
| Комната | Будущий полноценный UI пользователя | `profile/*` |
| Квесты | Упражнения-сценарии; будущее: персональные программы от ИИ-тренера в чате | `quest/*` |
| ДНК / GTRACK | Комната трека (структура/жанр/тональность/BPM/энергия) | `dna*` / `gtrack*` |
| «Сосуд» | Концепт: beLive ПОДСВЕЧИВАЕТ трек; наполнение трека ЗАЛИВАЕТ сосуд | архитектурный метафор |

## Пайплайн сервисов (карта внешних зависимостей)
MVSEP (stem-sep, API отложен → свой ключ у юзера) → ПОРТ/DUO (загрузка zip/duo) →
Genius (текст+секции → TrackMap авто) → lrclib (тайминги строк, кнопка Lines) →
GetSongBPM (BPM/тональность/ДНК, атрибуция-ссылка = баг #4) → gateway-align (пословная синхр) →
Telegram (TG-каталог ботом, ZIP/TG/Publish из Sync) → OpenRouter (свой AI для Билли + Built-in) →
Cloudflare-воркеры (АУДИТ ЖДЁТ скринов владельца).
