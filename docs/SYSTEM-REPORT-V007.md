## 3. Мост ПК ⇄ Мак (SSH + SSHFS)
### 3.1 ПК (V)
- `sshd` в WSL2 под systemd: `ssh.service` **enabled + active** (переживает ребут WSL).
- Фаервол Windows: правило `sshd-wsl` (Inbound, TCP/22, Allow, Profile=Any).
- Hyper-V/WSL фаервол: `DefaultInboundAction Allow` (отдельный слой, иначе WSL-трафик блокируется).
- Авторизация по ключу: публичный ed25519-ключ Мака прописан в `~/.ssh/authorized_keys` на ПК (без пароля).

### 3.2 Мак (M)
- FUSE-T 1.2.7 (kext-less) + sshfs 2.9 (`/usr/local/bin/sshfs`).
- Алиас `bepc` в `~/.ssh/config`:
  ```
  Host bepc
    HostName 192.168.0.14
    User nikit
    IdentityFile ~/.ssh/id_ed25519
    ServerAliveInterval 15
  ```
- Монтаж: `sshfs bepc:/home/nikit/projects/beLive ~/beLive-pc -o defer_permissions,reconnect,ServerAliveInterval=15,volname=beLive-PC`
- `~/beLive-pc` — **живая ссылка** на ПК-ФС (НЕ отдельный клон).
