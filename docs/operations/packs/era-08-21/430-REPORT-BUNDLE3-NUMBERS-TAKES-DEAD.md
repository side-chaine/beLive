## 2. 🔴 ПРОБЛЕМА: ЗАПИСЬ ТАЙКОВ НЕ РАБОТАЕТ В V3 (корень найден кодом)

### Симптомы (пользователь)
1. Запись тейка во вкладке Quest не работает — нажатие REC ничего не даёт
2. Canvas волны пустой: playhead движется, самой волны нет
3. Сценарии не работают (вероятно те, что завязаны на запись — уточнить)
4. Ошибок в консоли НЕТ — тишина

### Корень (`src/takes/takes.recorder.ts:69-75`)
```ts
if (!ae.microphone?.enabled) {
  const engineMode = import.meta.env.VITE_ENGINE ?? 'v2';
  if (engineMode === 'v3') {
    // UI: явное «недоступно в V3-режиме» (тост/бейдж), НЕ бросать, НЕ вызывать
    return;                    // ← ТИХИЙ ВЫХОД
  }
  await ae.enableMicrophone(); // ← V2-API, в v3 не вызывается
}
const stream = ae.getMicrophoneStream?.('raw')  // ← V2-API (AudioEngineV2.ts:1544)
if (!stream) throw new Error('Raw mic stream not available');
// ... MediaRecorder + AnalyserNode создаются НИЖЕ — не доходят
```

### Механика
- В v3 `start()` **молча возвращается**: ни MediaRecorder, ни AnalyserNode не создаются
- Волна пустая именно поэтому: canvas читает `recorder.analyser` = null; playhead живёт от транспорта и не зависит
- TRIM-BASIS логируется — телеметрия времени независима от захвата (поэтому «armed early» видно, а звука нет)
- Комментарий в коде **обещает тост/бейдж** «недоступно в V3» — **не реализован**. Пользователь получил немую кнопку

### Это известный дефицит (CONTEXT-007 §15.6, разведка M4)
«Микрофон в V3 — micInput есть, но getUserMedia НЕТ, setMicEnabled никто не вызывает → мёртв (takes на V2-mic, а V2 заглушён кейджем!)». Сейчас подтверждено живьём + найдена точная точка молчаливого отказа.

### Попутная находка
`[GUARD] CRITICAL: 36 markers out of bounds. Data migration needed.` (lyrics-events.ts:71) — при смене на трек B (1787200209918). Не блокирует воспроизведение (PS Travel работает), но GUARD кричит CRITICAL. Отдельная строка Ц3: данные маркеров трека B требуют миграции или порог GUARD ложно срабатывает.
