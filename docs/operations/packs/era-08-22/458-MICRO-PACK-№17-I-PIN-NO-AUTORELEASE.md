# 458-MICRO-PACK · №17-I · ПИН БЕЗ АВТО-РЕЛИЗА (финальная семантика юзера)

**Директива юзера (дословно):** «Блок не должен переключаться после остановки записи на текущем блоке. Нужно зафиксировать тот же самый блок, на который мы пишем take. Понятно?»

**ROOT оставшегося прыжка:** мой же №17-F (453) — авто-релиз пина при выходе транспорта из диапазона блока. Песня играет во время записи → к моменту стопа уже у/за границей → пин снялся → follow увёл панель в Pre-Chorus. Ровно то, что юзер видит и запрещает.

**Фикс:** УДАЛИТЬ блок авто-релиза №17-F целиком. Пин держит блок записи бессрочно; панель переключается ТОЛЬКО явными действиями юзера (клик чипа — работает через WagonTrain напрямую; новая запись перепинывает на новый блок; смена трека сбрасывает).
