## 2. Хронология по логу (факты)
```
[RECON-SEEK] seek(time=20.05) gen=1 isPlaying=true      ← клик по канвасу (работает, C22 ✅)
[TRACE] play() return: state not ready/paused           ← no-op: V3 уже играет (state=playing) — НОРМАЛЬНО
[RECON-SEEK] seek(time=17.05) gen=2 isPlaying=true      ← pre-roll seek на 17.05 = 20.05 - PRE_ROLL(3) ✅ V3-путь работает
[TakesControlStrip:266] [TRIM-BASIS]                    ← trim-логика отработала
```

**Старт записи = 21.882с, при старте блока 20.05с → запись началась на 1.83с ПОЗЖЕ начала блока. Между seek(17.05) и стартом записи прошло 4.83с.**

## 3. Корневая причина (одна, подтверждена кодом)

В `TakesControlStrip.handleRecord` (:133-313) порядок такой:

```
:166  ae.setPlaybackRate(1)          ← V2-метод (для V3 не влияет — риск №2)
:177  await ae.enableMicrophone()    ← getUserMedia (async!)
:187  seekTo(preRollStart=17.05)     ← V3-seek, void (не ждём) ✅ работает
:188  getTransport().play()          ← V3 уже играет → no-op ✅ (не баг)
:193  await recorder.start()         ← ⚠️ ЕЩЁ РАЗ микрофон: stream+MediaRecorder+analyser
:199  countdown-цикл (rAF)           ← СТАРТУЕТ ТОЛЬКО ЗДЕСЬ — после async-микрофона
:246  startRecording() → store       ← «запись идёт» (после countdown)
:293  timeCheck (ct >= blockEnd)     ← C22: работает по V3-тайму ✅
```

**`await recorder.start()` (:193) включает `enableMicrophone()` → `getUserMedia()` — первый запрос после перезагрузки страницы занял ~4.8с.** Всё это время трек уже играет с 17.05. К моменту старта countdown-цикла позиция = 21.88 — УЖЕ ВНУТРИ блока (старт 20.05):

- `left = startTime - ct = 20.05 - 21.88 < 0.05` → **мгновенный resolve на первом же тике**
- `setCountdown(3)` → `setCountdown(null)` в одном кадре → **React батчит → оверлей «3-2-1» НЕ РЕНДЕРИТСЯ ВООБЩЕ**
- Запись стартует «молча» в 21.88, MediaRecorder пишет от 21.88 (trim = 1.83с обрежется)

**Pre-roll протухает из-за async-инициализации микрофона, которая стоит МЕЖДУ seek+play и countdown.**

## 4. Почему «записи нет» (восприятие пользователя)
- Countdown-оверлей не показался (п.3).
- Индикатор записи на слоте: тонкая красная рамка + «● Record» — но надпись «● Record» на пустом слоте висит ВСЕГДА (это приглашение, TakeSlot.tsx:129) — не отличить от состояния записи.
- Live-trail (DAW-волна) стартует только после `startRecording` (:246) — то есть с прогресса ~21.88/блок, с середины, без видимого «начала».
- Итог: пользователь не получил НИ ОДНОГО явного сигнала «запись пошла».

## 6. Риски (отдельно от корня, для плана)
- **Риск 1 (tempo-aware training):** `ae.setPlaybackRate(tempoRate)` (:166-170) — V2-метод, на V3-темп не влияет → training-записи (замедленный темп) при V3-фоне лягут в неправильном темпе/trim. Нужно `TransportV3.setRate()` (или эквивалент).
- **Риск 2 (мониторинг):** enableMicrophone роутит микрофон в V2-шину, V2-выходы закейджены → при V3-фоне певец может не слышать себя (запись raw-потока при этом пишется корректно). Проверить пользователем при живом тесте.
- **Риск 3 (line-scoped preRoll=0):** при `scope.lineRange` pre-roll = 0 и countdown не показывается ПО ДИЗАЙНУ — пользователь тоже не увидит отсчёта, но это ожидаемое поведение (в логе был preRoll=3, т.е. не наш случай).
- Гонки seek→play нет: `play()` при state='playing' — молчаливый no-op (:135-138) — подтверждено кодом и логом.

## 7. План фикса (пакет 422 — на утверждение Ц3)
1. **Порядок:** поднять микрофон ДО seek+play: `await recorder.start()` перенести ПЕРЕД `seekTo(preRollStart)`+`play()` (микрофон готов → pre-roll не протухает).
2. **Wall-clock countdown:** тикать по `performance.now()` от момента seek (не по engine-time) — устойчиво к любым гонкам времени; цифра всегда 3-2-1 по wall-clock.
3. **Защита протухания:** если при старте countdown `ct >= startTime + 0.05` → повторный seek на `preRollStart` и перезапуск цикла (или отмена с уведомлением).
4. **REC-бейдж:** крупный «● REC» на канвасе при `isRecording` (как в DAW) — явный фидбек старта записи.
5. **Риск 1:** tempoRate → через V3 (`TransportV3.setRate`), только если флаг `__v3Active`; иначе как сейчас.
6. Риск 2 — отдельная задача (не входит в 422).
