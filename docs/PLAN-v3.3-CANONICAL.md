канон-запись реестра): на момент Этапа 0 — tsc 306, vitest 772 passed (2 legacy
missing-import вне счёта); формулировка А4 едина: «tsc N / vitest passed M, files X/Y,

полный отчёт + живой ретест. Proof-of-change: race/async/lifecycle-фикс
принимается только с доказательством изменения поведения (тест или
трейс-дифф). Уровни верификации: статика 🟡 / CDP-драйв 🟢 / уши ✅.
