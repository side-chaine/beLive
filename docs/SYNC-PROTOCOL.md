# SYNC-PROTOCOL — ПК ⇄ Мак: единый репозиторий

> Статус: активно с 2026-08-23. Собрано агентом 007 по прямому запросу Никиты.
> См. также отчёт Мак-агента «СИСТЕМА ЕДИНА (v3)».

## 1. Принцип
- **ПК (WSL2, `/home/nikit/projects/beLive`) = КАНОНИЧЕСКИЙ репозиторий.** Все правки ведутся здесь.
- **Мак = сателлит через SSHFS-монтаж:** `bepc:/home/nikit/projects/beLive → ~/beLive-pc`.
  Это **НЕ отдельный клон** — живая ссылка на ПК-файловую систему.

## 2. Как Мак получает объективное состояние репозитория
1. **Файлы** — видны **мгновенно**: sshfs отражает ПК-ФС в реальном времени. Любая правка
   на ПК сразу видна на Маке без каких-либо действий.
2. **Сводка состояния** — файл `REPO-STATE.md` в корне проекта. Автоматически перезаписывается
   git-хуком (`post-commit` / `post-merge` / `post-checkout`) на ПК при каждом коммите. Содержит:
   ветка, HEAD, последний коммит (msg/author/date), число незакоммиченных изменений, последние 5 коммитов.
3. **Незакоммиченные изменения** — Мак выполняет `git status` / `git diff` прямо в `~/beLive-pc`
   (там же `.git`, смонтированный).

## 3. ПРАВИЛО (обязательное)
- Мак работает **ТОЛЬКО внутри `~/beLive-pc`** (монтаж). **Никаких отдельных `git clone` на сам Мак** —
  иначе возникнет рассинхрон копий.
- После каждой правки на ПК: если сделан `commit` → `REPO-STATE.md` обновляется автоматически,
  Мак читает его для сводки.
- Для live-статуса без коммита: Мак смотрит файлы напрямую или `git status` в монтаже.
- ❄️ **FROZEN-ZONE** (`AudioEngineV2.ts`, `patchV1.ts`, `bridges/*`, `track.orchestrator.ts`,
  приватные `_`) и **dispatch-только-через-007** действуют на ОБЕИХ сторонах без исключений.

## 4. Заметки реализации
- Хук: `.git/hooks/update-repo-state.sh` (вызывается из `post-commit`/`post-merge`/`post-checkout`).
- `REPO-STATE.md` добавлен в `.gitignore` → не грязнит дерево коммита и не попадает в историю.
- Хук срабатывает при коммитах через **WSL-git** (агенты / OpenCode на ПК). Если коммит делается
  Windows-клиентом git, `REPO-STATE.md` обновится при следующем WSL-коммите; live-файлы и
  `git status` на Маке при этом остаются актуальными (sshfs).
- Для ручного обновления без коммита: `bash /home/nikit/projects/beLive/.git/hooks/update-repo-state.sh`
