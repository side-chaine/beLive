## 🔬 МЕТОД — ЭТО И ЕСТЬ ВЕСЬ ВКЛАД

Предшественник дал результат не потому, что был Opus, а потому что **проверял вместо доверия к грепу**. Пять правил, каждое с ценой нарушения из реальной практики:

**1. Проба важнее грепа.** Греп говорит, что текст есть. Проба говорит, что код исполняется.
   - `probe-tsconfig` с `exclude` — узнать реальную tsc-дельту сноса, не тронув файл
   - `npx vite build --minify false --outDir /tmp/...` — узнать, попадает ли файл в бандл
   - самописный обход графа импортов — узнать достижимость (но см. правило 5)
   - **Цена нарушения:** «−116 ошибок» оказалось −7. Цифру взяли пересказом, не пробой.

**2. Любую пробу откатывать и проверять откат.** `git status`/`git diff --stat` после. Временный `tsconfig.probe.json` — удалить и убедиться `ls` что удалён.

**3. Карточка клейма на каждом стыке.** Формат обязателен:
   ```
   УТВЕРЖДЕНИЕ | ДОКАЗАТЕЛЬСТВО (file:line ИЛИ команда+вывод) | ПРОВЕРЕНО: кем/чем | СКОУП
   ```
   «НЕ ПРОВЕРЕНО» — легальное значение поля. Пустое поле — нет. **Цифра без скоупа не является клеймом.**

**4. Список «НЕ ПРОВЕРЕНО» — часть спеки, не оговорка.** В каждом паке отдельным блоком. Он нужен 002 и 009 больше, чем список доказанного.

**5. Свои же инструменты проверять на живых данных.** Гейт может выглядеть работающим и врать.
   - **Цена нарушения (свежая):** `scripts/verify-reach.mjs:53` — один регексп на все формы импорта, `[\s\S]*?` пересекает переводы строк, bare `import 'x';` съедается вместе со следующей строкой ⇒ **~76 ложных «недостижимых» из 206**, включая ядро (`V3DataInterceptor.ts`) и **пилот Д-5 `InstrumentStrip.tsx`**. Фикс: три отдельных прохода (`from`-форма · `^\s*import\s+['"]` с флагом `/m` · `import(`), стриппить комментарии, вычитать `*.test.*`/`__tests__`.

## ❄️ FROZEN — состояние на передаче

Директива Никиты 02.09 20:53 (коммит `3671705e`): **«мы убираем полностью — Frozen быть не должно»**. Программа де-фриза идёт до `frozen 0/0`, сейчас 2/2. OVERRIDE действует, но:
- любое упоминание frozen-файла любым агентом в цепи — **повод перепроверить факт**, а не молча продолжить;
- `frozen 0/0` — **бухгалтерия, не цель**. Замок сегодня охраняет два файла, из которых один не попадает в бандл вообще, второй патчит объект с 0 писателями. Настоящая цель — репо без правдоподобно выглядящего мёртвого кода, и её замок никогда не проверял. **Поэтому программа обязана закончиться шагом D-4 — заменой замка на гейты живости.** Иначе через месяц вырастет новое созвездие, и снова никто не заметит.
