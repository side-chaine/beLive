# LESSONS.md · Уроки пары 006↔007 (+008) · beLive V3 · пополняется по факту

## L1 · Ловушка соседних строк консоли
Соседние строки лога ≠ соседние моменты времени. Между ними могут быть секунды пользовательских действий (запись тейка!). Перед причинной цепочкой — проверять wall-time разрывы или добавлять цифры в саму строку лога.
*Цена: цикл доп14→доп16 (ложная гипотеза «дрейфа часов»).*

## L2 · Перечисли ВСЕ триггеры ДО выреза
Фикс симптома начинается с grep всех коллеров причинного действия, не после. Один симптом — пять двигателей (№17: :365, :39, auto-follow, PS Travel, субблок-клик).
*Цена: 442 применён в неверном месте.*

## L3 · Proof-of-change гейт ловит ложные закрытия
Ни одно «готово» без поведенческого доказательства: ретест юзера / трейс с цифрами / скрин через 008. Сработал трижды (442, B2, F).

## L4 · Паттерн stale-cache / freeze-on-pause
Публикуемые кэши (`__belive.currentTime`) пишутся только при playing → замерзают на паузе навсегда; publishSeek кэш не обновлял. Любой потребитель кэша обязан либо читать прямой источник (TransportV3.currentTime — паттерн D/G/A), либо издатель обязан обновлять кэш на seek (пак E).
*Открытие: 006 независимо + 007 частично; полный синтез только вдвоём.*

## L5 · Минимальный радиус взрыва
Движковые правки откладываются, пока локальные не позеленели в ретесте (E отложена дважды осознанно). Сначала панель, потом транспорт.
